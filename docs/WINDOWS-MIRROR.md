# NaomiPhone Mirror для Windows 11

Клиент показывает экран Xiaomi Pad 6 (pipa) или рабочий стол PopkaPhone. На рабочем столе мышь работает как мышь. В режиме «Экран планшета» щелчок и перетаскивание работают как касание, а колесо и трекпад прокручивают содержимое.

## Установка и запуск

Установите Node.js с npm и Python 3. Для USB нужны Android Platform Tools и ADB-интерфейс планшета. Launcher ищет adb в `PATH` и в `C:\adb\adb.exe`. Для Wi-Fi нужен клиент OpenSSH Windows. Выполните из корня репозитория в PowerShell.

~~~powershell
npm --prefix mirror install
py -3 .\tools\mirror_win.py --via usb --adb <ADB_SERIAL>
~~~

При первом запуске Electron может скачать исполняемый файл. Если в ADB одно готовое USB-устройство, параметр `--adb` можно опустить. Launcher выделяет свободный локальный порт через `adb forward` на TCP-порт планшета 8478 и снимает свой проброс при закрытии окна.

Для Wi-Fi подставьте адрес планшета в локальной сети.

~~~powershell
py -3 .\tools\mirror_win.py --via wifi --host 192.168.1.42
~~~

На планшете должен работать SSH для пользователя `phablet`. Положите в `private/ssh` ключ `naomiphone_ed25519`, авторизованный на планшете, и `known_hosts` с проверенным ключом **этого планшета** под именем `naomiphone`. OpenSSH передаёт видео и ввод через `ssh -W` к службе на `127.0.0.1:8478`. Параметр `--port` меняет порт самой службы для обоих способов подключения. [Протокол трансляции](STREAM.md).

Если OpenSSH сообщает `bad permissions` для скопированного ключа, проверьте, что файл принадлежит вашей учётной записи и доступен только ей. У скопированного файла с унаследованными правами их можно заменить этой командой. [Требования Win32 OpenSSH](https://github.com/PowerShell/Win32-OpenSSH/wiki/Security-protection-of-various-files-in-Win32-OpenSSH).

~~~powershell
$account = whoami
icacls.exe .\private\ssh\naomiphone_ed25519 /inheritance:r /grant:r "$($account):F"
~~~

Режим `--via auto` используется по умолчанию. Он начинает с USB и использует Wi-Fi при отсутствии рабочего USB-пути, если адрес задан через `--host` или сохранён в поле `wifi_ip` файла `private/device.json`. Адрес можно указать явно и при подключённом кабеле. Если при переподключении кабеля ADB потерял проброс, перезапустите launcher для восстановления USB.

На планшете включите «Трансляцию» в шторке или настройках. Клиент появляется в разделе «Экраны» как Windows (win). Если окно показывает обои с часами, щёлкните в нём или назначьте ему рабочий стол в разделе «Экраны». [Управление экранами](SCREENS.md).

## Клавиши

Список также доступен в меню **Справка → Сочетания клавиш**. Клавиши действуют, пока окно в фокусе.

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+1 / Ctrl+Alt+2 | Рабочий стол / экран планшета |
| Ctrl+Alt+I | Статистика изображения и связи |
| Ctrl+V | Вставить текст из буфера Windows. На рабочий стол также идёт команда Ctrl+V для «Файлов» |
| Ctrl+C, Ctrl+X, Ctrl+A, Ctrl+Z | Копировать, вырезать, выделить всё, отменить в приложении на планшете |
| Esc / Alt+↑ / Alt+↓ в режиме планшета | Назад / домой / шторка |
| Alt+↑, Alt+← / Alt+→, Alt+Backspace, Enter, Ctrl+H на рабочем столе | В «Файлах» наверх, назад / вперёд, в корзину, открыть, показать скрытые |
| Shift+Alt+3 / Shift+Alt+4 на рабочем столе | Снимок всего рабочего стола / его области |

## Сборка

~~~powershell
npm --prefix mirror run build:win
py -3 .\tools\mirror_win.py --via usb --adb <ADB_SERIAL> --exe ".\mirror\dist\NaomiPhone Mirror-win32-x64\NaomiPhone Mirror.exe"
~~~

Electron Packager создаёт переносимую папку x64 в `mirror/dist`. Для переноса копируйте папку приложения целиком. С параметром `--exe` launcher запускает собранный клиент без npm. Для Wi-Fi он берёт ключи и адрес из `private/` в корне репозитория.

## Видео и различия платформ

- Electron принимает H.264 и HEVC в Annex B. На Windows WebCodecs проверяет аппаратный HEVC для кадра 2880×1800. Если он недоступен или декодер выдаёт ошибку, клиент запрашивает H.264 с возможностью программного декодирования. Кодек общий для всех зрителей, поэтому при активном HEVC-зрителе запрос H.264 может потребовать закрыть его. [WebCodecs](https://www.w3.org/TR/webcodecs/).
- В Windows используются системный заголовок, значок ICO с резервным PNG и меню «Вид» и «Справка» в единственном окне Electron. На macOS остаются Cmd, сочетания Finder, VideoToolbox и управление AWDL. POSIX-скрипт `tools/mirror` запускает Electron из npm, а `mirror/build.sh` собирает приложение macOS с `iconutil` и `codesign`. Адрес Wi-Fi окна берётся из `private/device.json`. Имя Bonjour `naomi-pi.local` относится к приставке. [Документация приставки](PI.md).

## Проверка

~~~powershell
npm --prefix mirror test
py -3 -m unittest discover -s tools/tests -v
~~~

На Windows 11 проверены сборка x64 и запуск с локальными TCP- и SSH-моками. Клиент показал кадры H.264 и HEVC размером 2880×1800, перешёл на H.264 после ошибки HEVC и передал события мыши, колеса, касания, клавиатуры и текст тестового буфера.
